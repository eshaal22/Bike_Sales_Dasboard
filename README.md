# Bike Sales Dashboard

An Excel data project that looks at customer data to see who buys the most bikes.

## 📊 Key Features
* **Income Analysis:** Shows that people with higher incomes buy more bikes.
* **Commute Distance:** Shows how far people travel and how it affects their purchase.
* **Age Groups:** Groups customers into young, middle-aged, and old brackets.
* **Interactive Slicers:** Buttons to easily filter the charts by Region, Education, and Marital Status.

## 🛠️ Tools Used
* **Data Cleaning:** Removed duplicates and fixed missing values.
* **Formulas:** Used Excel `IF` statements to group customer ages.
* **Pivot Tables & Charts:** Built interactive graphs and aligned them perfectly.
